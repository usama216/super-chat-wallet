✓ That's the full flow

  • Every coin is accounted for. Each move is a double-entry ledger record that adds up to zero.
  • No double charges. Retrying the same request returns the first result and charges nothing.
  • No overspending. Wallets are locked while a payment runs, so the balance can't go below zero.
  • Refunds are clean. A refund writes the exact opposite entries, so the history stays intact.
